# mpp5 — Python × MediaPipe × p5.js

ローカルカメラの姿勢推定を、p5.js のインタラクティブな海中ディスプレイにつなぐ最小プロトタイプです。外部AI APIは使わず、カメラ映像を保存・送信しません。

## 構成

- **Python + OpenCV**: ローカルカメラを取得
- **MediaPipe Pose**: 姿勢ランドマークを推定
- **FastAPI + WebSocket**: ローカル端末内で姿勢イベントをブラウザに配信
- **p5.js**: 泡、イルカ、海中エフェクトを描画

カメラ映像そのものはブラウザに送らず、正規化した姿勢情報のみを `127.0.0.1` 上で配信します。

## 起動方法 (Windows / PowerShell)

Python 3.11 または 3.12 を推奨します。MediaPipeの配布wheelの対応状況により、Python 3.13ではインストールできない場合があります。

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python server.py
```

ブラウザで http://127.0.0.1:8765 を開き、カメラ使用を許可してください。サーバー起動時にローカルカメラを開きます。終了はターミナルで `Ctrl+C`。

Python 3.11ランチャーがない場合は `py --list` で利用可能なPythonを確認してください。

## 操作

- 左右に体を傾ける: イルカを左右へ誘導
- 両腕を左右に広げる: 泡の輪を発生
- しゃがむ: 深海モードへ移行
- 姿勢が検出されない: イルカは中央へ戻り、入力状態をリセット

カメラは全身が映る位置に置き、明るい場所で試してください。複数人が同時に映る場合の追跡・個人識別は実装していません。

## トラブルシューティング

- **Camera unavailable**: Windowsのカメラプライバシー設定でデスクトップアプリのカメラ利用を許可し、他のアプリがカメラを占有していないか確認。
- **MediaPipe import error**: Python 3.11/3.12の仮想環境を作り直して依存関係を再インストール。
- **ブラウザに接続状態が出ない**: `http://127.0.0.1:8765` を開き直し、ターミナルに出たエラーを確認。
- **動作が重い**: カメラ解像度を下げ、照明を改善してください。

## プライバシー

映像・画像・音声をディスクへ保存しません。ランドマーク由来の数値をローカルWebSocketで配信するだけです。試遊研究に拡張する際は、保護者への説明・同意、データ最小化、保存期間、削除手順を別途設計してください。
